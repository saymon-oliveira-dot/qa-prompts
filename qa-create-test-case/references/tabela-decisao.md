# Tabela de decisão

Leia somente quando a heurística 3 se aplicar. Uma condição isolada não entra aqui: ela já é coberta pela heurística "Regra de Negócio Explícita".

## Quando aplicar

O texto descreve 2 ou mais condições independentes que se combinam para determinar um resultado.

Exemplo sustentado pela fonte: tipo de cliente + faixa de valor definem o desconto aplicado.

## Como montar

Monte a combinação de condições × ação/resultado como passo de raciocínio. Esta tabela é a Parte 3 e só aparece na saída quando esta heurística se aplicar.

Cada linha precisa estar mencionada na fonte ou decorrer logicamente dela. Não acrescente combinação hipotética.

| Condição A | Condição B | Ação / resultado |
|---|---|---|
| valor explícito na fonte | valor explícito na fonte | resultado explícito na fonte |

Cada linha sustentada vira um cenário. O formato do cenário está em [saida.md](saida.md).
